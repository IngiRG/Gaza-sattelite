About this project

Data source: Copernicus Sentinel‑2 Level‑2A imagery processed from Element 84 Earth Search open data.

Method: Left map: 27 Sept 2023. Right map: one low‑cloud Sentinel‑2 scene for each month. Tiles are generated by GitHub Actions.

Independence: This is an independent visualization project and is not affiliated with ESA, the Copernicus Programme or Element 84.

Interpretation: The application displays satellite imagery as recorded and does not make claims about the causes of visible changes.
