About this project

Data source: Copernicus Sentinel‑2 Level‑2A imagery processed from Element 84 Earth Search open data.

Method: Left map: 27 Sept 2023. Right map: one low‑cloud Sentinel‑2 scene for each month. Tiles are generated by GitHub Actions.

Independence: This is an independent visualization project and is not affiliated with ESA, the Copernicus Programme or Element 84.

Interpretation: The application displays satellite imagery as recorded and does not make claims about the causes of visible changes.

Attribution: © European Union, Copernicus Sentinel‑2.

Recorded Israeli attack events

A conservative subset of UCDP georeferenced events from 7 Oct 2023 onward. An event is shown only when UCDP text explicitly describes Israeli or IDF forces as carrying out the attack. Events merely involving Israel, or describing attacks on Israel, are excluded.
Important: UCDP does not provide a universal event-level attacker field. To avoid mixing attacks on Israel with attacks by Israel, this map includes only records whose UCDP text explicitly identifies Israeli/IDF forces as the actor carrying out the attack. Ambiguous events are omitted, so this is intentionally incomplete.
